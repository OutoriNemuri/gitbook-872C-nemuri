# 宏观宇宙

宇宙没有名字，可被称作 **P01**。

| 项目 | 设定 |
| --- | --- |
| **宇宙名** | 无，可被称作 P01 |
| **实际统治者** | 世神ミグヨ |
| **结构** | 多层级复合三维空间，每层级由小型完整宇宙（称为“世界”）构成 |
| **大小** | 理论无限 |
| **年龄** | 至少 13750 万年（文川考古）；据推测至多有 25 垓年（从平面延展判断） |
| **重置次数** | 整体未曾重置；一些世界曾单独重置 |
| **构成** | 不固定，世界内依世界变化决定；世界外均为[纯中子简并态物质](degenerate-matter.md) |
| **规则统一性** | 宇宙标准秒，每秒约合现实 0.975 秒 |
| **时间** | 无标准。世界内遵循世界，世界外不存在时间 |
| **空间** | 无标准。世界内遵循世界，世界外不明（纯中子简并态物质） |
| **物理法则** | 目前已探明世界均遵循万有引力定律，不确定是否为宇宙统一标准 |

---

## 结构说明

宇宙是**多层级的复合三维空间**。它的每一个层级称为一个[平面](planes.md)，而每个平面中又包含大量三维空泡。当一个空泡符合一定条件时，它就会成为一个**小型完整宇宙**，称为**世界**。

这一结构决定了宇宙的两层嵌套特征：

- **平面**是宇宙的骨架，无限延展；
- **世界**是宇宙的血肉，各自拥有独立的物理法则、时间流速与空间尺度。

世界之外的一切空间，均为纯中子简并态物质填充。

---

## 时间与空间

宇宙本身**没有统一的时间与空间标准**。时间只在世界内有意义：每个世界遵循自己的时间体系；而在世界外，时间根本不存在。

空间的情况类似——世界内的空间尺度由该世界自身的规则决定，世界外的空间性质不明，因为那里只有纯中子简并态物质。

唯一近似“宇宙标准”的度量是**宇宙标准秒**：1 宇宙标准秒 ≈ 现实 0.975 秒。

---

## 物理法则

目前已探明的所有世界**均遵循万有引力定律**。

但这不足以断言万有引力是宇宙的统一标准——探明的世界只是全部世界中的极小一部分，宇宙的物理法则是否存在统一基准，仍是未解问题。
