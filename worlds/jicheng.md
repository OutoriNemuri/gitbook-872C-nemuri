# 寂城

**寂城**位于[主平面](../universe/planes.md)。该世界本身只有一个大陆和一个岛屿。

---

## 基本档案

| 项目 | 设定 |
| --- | --- |
| **总面积** | 480 万平方公里 |
| **国家数** | 无国家概念，仅有“省”的概念，全体共 **8 个省** |
| **时间** | **有序轮回，周期为 137 年** |
| **大气** | 较为稀薄，含氧 7%，氮 80% |
| **物理法则** | 其他完全符合现实世界基本定律 |

---

## 社会特征

寂城，正如其名，**绝大部分人都处于抑郁中**。

### 寂之祭

本地人的一些物件上会出现“**寂之祭**”标识，用来表示此人的抑郁程度：

- **蓝色三角**越多 → 此人越**抑郁**
- **红色圆形**越多 → 则**反之**

### 管辖

寂城**无统一管辖人或单位，也没有法律**。

由各省建立者及其他“职员”单独进行该省的管辖。民间组织**可以脱出省进行独立**（例如 MusExpo 音乐社）。
