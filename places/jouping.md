# 上平

> **元叙事角度**：上平国融合了凤眠对**日本文化和亚文化**的喜爱，以及凤眠阅读的各种作品的融合。

## 时空混乱后的非人类生物

在 **2249 年**[文川](../worlds/wenchuan.md)时空混乱产生后，根据文川联合国统计数据，上平新增非人类生物共计 **38,200 余类**，其中：

| 类别 | 数量 |
| --- | --- |
| 猫娘 | 102 |
| 伪人 | 317 |
| 拟态生物 | 124 |
| 其他 | 余下部分 |
